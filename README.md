# Telecommunications Customer Churn Classification

## Overview
This project evaluates customer churn in the telecommunications industry using classification algorithms on a dataset of over 7,000 customer records[cite: 1]. The analysis compares Logistic Regression and Decision Tree models to identify churn risk factors and actionable retention strategies[cite: 1].

## Key Results
- **Top Performing Model:** Logistic Regression (79.18% Accuracy, 72.38% Sensitivity)[cite: 1].
- **Key Risk Drivers:** Month-to-month contracts and fiber optic internet service were the strongest indicators of churn[cite: 1].
- **Key Loyalty Indicator:** A higher number of dependents strongly correlated with increased customer retention[cite: 1].
